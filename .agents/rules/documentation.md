# Documentation Guidelines

- **No emoji spam:** Keep markdown documentation, README files, and guides clean, professional, and technical. Avoid decorative emojis in headings, lists, and section dividers.
- **Clear structure:** Use standard markdown headings, tables, and concise bullet points.
- **Instant File Explorer Launchers:** Always include double-clickable `.bat` launcher scripts in project root directories preconfigured with `--rendering-method gl_compatibility` and target scene flags so any project or showcase starts immediately without needing terminal commands or opening the editor.
